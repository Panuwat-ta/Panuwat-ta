## Featured project

### [ScamGuard — scam image detection](https://github.com/Panuwat-ta/project)

Capstone. Detects edited images and scores risk, with a mobile app, API, and admin portal.

- Built the Flutter app with Clean Architecture and BLoC state management.
- Built the FastAPI backend with JWT auth, rate limiting, and Redis caching for image hashes.
- Connected ONNX SegFormer MiT-B2 for pixel-level tampering signals and Surya OCR for Thai/English text, then combined them into one risk score.
- Shipped with SRS docs, C1–C4 diagrams, Pytest API tests, and Jira sprints.

`Flutter` `FastAPI` `React` `Python` `ONNX` `PostgreSQL` `Redis`
